# 更新日志

## 1.1.0

- 新增 **Workbench Sync** 本地插件：笔记实质变化后自动重新生成导航页与展厅
- 去抖 8 秒 + 最低同步间隔 5 分钟；手动「立即同步」不受限
- 只改空格/空行不触发；Inbox 变化不触发，整理进主题目录才触发
- 延迟期间关闭 Obsidian，pending 状态持久化，下次启动补跑
- 新增 `生成玻璃展厅.py`：展厅数据自动生成
- 两个生成脚本支持未跟踪的新笔记（日期回退到文件创建时间）
