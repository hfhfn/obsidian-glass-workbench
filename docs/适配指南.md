# 适配指南

模板从作者的知识库抽取，默认链接指向示例目录（AI大模型、工作、AIGC 等）。迁移到你的 vault 后需要改三类东西。

## 1. 替换 MOC / 笔记链接

涉及文件：

- `00_系统/工作台.md`
- `00_系统/交互工作台.md`
- `00_系统/配色方案.md`
- `00_系统/工作台-玻璃展厅.html`

把 `[[AI大模型/AI大模型-MOC]]`、`[[工作/面试收集/面试收集-MOC]]` 等改成你自己的 MOC 路径。最简单的方式：打开笔记，用 Obsidian 的「查找替换」批量替换目录名。

## 2. 替换 vault ID

展厅 HTML 使用：

```text
obsidian://open?vault=YOUR_VAULT_ID&file=...
```

把 `YOUR_VAULT_ID` 替换为你的 vault ID。查看方式：

- Windows：`%APPDATA%\obsidian\obsidian.json` 中 `vaults` 的键
- 或 Obsidian 设置 → 关于 → 高级（部分版本可见）

## 3. 调整指标卡

`00_系统/交互工作台.md` 的 `topics` 数组：

```js
{ label: "AI 大模型", value: cnt(p => has(p, "AI大模型/")), ... }
```

把 `AI大模型/` 改成你的目录；新增卡片复制一行即可。

## 4. 调整导航脚本

`00_系统/脚本/生成知识库导航页.py` 顶部的：

```python
EXCLUDE_TOP = {"00_系统", "00_Inbox", "template", ".claude", "private"}
EXCLUDE_BASE = {"README", "CLAUDE"}
CURATED = [...]
```

按你的目录结构和常用入口修改。

## 5. 生成导航页

```bash
python "00_系统/脚本/生成知识库导航页.py"
```

## 6. 可选：主题

套件默认适配 Blue Topaz；其他主题也能用，但 `appearance.json` 中的 `cssTheme` 需要按实际主题调整，或直接删掉该字段。
