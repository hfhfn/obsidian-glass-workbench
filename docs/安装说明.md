# 安装说明

## 0. 环境

- Obsidian 1.15.1（最低建议 1.13+，Homepage 4.6 要求）
- 主题：Blue Topaz（可选；套件不强制主题）

## 1. 复制文件

把仓库里的：

- `vault-template/00_系统/` → 你的 vault 根目录
- `vault-template/.obsidian/snippets/glass-workbench.css` → 你的 `.obsidian/snippets/`

## 2. 安装插件

在 Obsidian 社区插件市场安装并启用：

1. **Dataview** — 数据查询
2. **Homepage** — 启动打开工作台
3. **Tasks** — 待办查询
4. **Style Settings** — 配色/模糊/双栏开关
5. **Keep the Rhythm** — 收录热力图
6. **HTML Reader** — 打开展厅 HTML（可选）

版本参考：`.obsidian/plugins-config/plugin-versions.md`。

## 3. 启用 CSS 片段

设置 → 外观 → CSS 代码片段 → 刷新 → 打开 `glass-workbench`。

## 4. 开启 DataviewJS

设置 → Dataview → **Enable JavaScript queries** 打开。
否则 `交互工作台` 会显示 “Dataview JS queries are disabled”。

## 5. 设置 Homepage

设置 → Homepage：

- 主页：`00_系统/工作台`
- 打开 **Open on startup**
- 打开 **Refresh Dataview**
- 建议打开 **Pin**

也可以手动用命令 `Homepage: Open homepage` 打开。

## 6. 生成知识库导航页

在 vault 根目录执行：

```bash
python "00_系统/脚本/生成知识库导航页.py"
```

脚本按 git 首次入库日期生成「高频入口 + 按月收录时间线」。需要 vault 是 git 仓库。

## 7. 适配

见 [适配指南.md](适配指南.md)。

## 8. 验证

- 打开 `00_系统/工作台`：应有最近收录、快捷入口、待办、热力图
- 打开 `00_系统/交互工作台`：应有 8 张指标卡、筛选栏、最近列表；点击卡片能打开笔记
- 打开 Style Settings：应看到「Prism Glass 工作台」及 18 套配色
- 浏览器打开 `00_系统/工作台-玻璃展厅.html`：应看到流体卡片，点击卡片跳回 Obsidian
