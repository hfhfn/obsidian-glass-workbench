# 配置说明

## Style Settings

路径：设置 → Style Settings → **Prism Glass 工作台**。

| 设置项 | 说明 |
|---|---|
| 配色方案 | 18 套（US-00 ~ US-25），含 4 套炫彩 |
| 炫彩渐变 | 多色环境光、旋转流光头图、渐变数字、渐变卡片边框 |
| 玻璃模糊强度 | `--pg-blur`，0–40px |
| 卡片圆角 | `--pg-radius`，10–34px |
| 双栏工作台 | 阅读视图两栏 |
| 关闭背景光晕 | 去掉固定环境光 |
| 关闭玻璃模糊 | 省电/移动端 |
| 关闭配色（跟随主题） | 回到主题原生颜色 |

## 配色 ID

- 沉稳：US-00 青绿、US-11 蓝金、US-08 深蓝紫、US-05 青紫、US-02 紫金、US-13 冰蓝、US-15 森林绿、US-12 湖蓝、US-16 墨蓝琥珀、US-17 石墨电蓝、US-18 东京夜、US-19 雾青莫兰迪、US-20 紫檀玫金、US-21 岩灰赤陶
- 炫彩：US-22 霓虹青紫、US-23 落日烈焰、US-24 糖果电波、US-25 极光蓝绿

完整色值与对比度见 `00_系统/配色方案.md`。

## 单篇覆盖

在笔记 frontmatter：

```yaml
cssclasses:
  - glass-dashboard
  - pg-us22
```

## CSS 变量

主要变量：`--pg-c1..c5`、`--pg-canvas`、`--pg-surface*`、`--pg-border*`、`--pg-text*`、`--pg-accent*`、`--pg-gradient`、`--pg-radius-card`、`--pg-blur-size`。

## 关闭整套玻璃

设置 → 外观 → CSS 代码片段 → 关闭 `glass-workbench`。不会影响笔记内容。
