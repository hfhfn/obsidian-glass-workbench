# 配置说明

## Style Settings

路径：设置 → Style Settings → **Prism Glass 工作台**。

| 设置项 | 说明 |
|---|---|
| 配色方案 | 18 套（US-00 ~ US-25），含 4 套炫彩 |
| 炫彩渐变 | 多色环境光、旋转流光头图、渐变数字、渐变卡片边框 |
| 玻璃模糊强度 | `--pg-blur`，0–40px |
| 卡片圆角 | `--pg-radius`，10–34px |
| 双栏工作台 | 阅读视图两栏 |
| 关闭背景光晕 | 去掉固定环境光 |
| 关闭玻璃模糊 | 省电/移动端 |
| 关闭配色（跟随主题） | 回到主题原生颜色 |

```yaml
  - pg-us22
```

## CSS 变量

主要变量：`--pg-c1..c5`、`--pg-canvas`、`--pg-surface*`、`--pg-border*`、`--pg-text*`、`--pg-accent*`、`--pg-gradient`、`--pg-radius-card`、`--pg-blur-size`。

## Workbench Sync

路径：设置 → **Workbench Sync**。

| 设置项 | 默认 | 说明 |
|---|---|---|
| 启用自动同步 | 开 | 笔记实质变化后重新生成导航页/展厅 |
| 去抖时间 | 8000ms | 停手多久后检查；只改空格/空行不触发 |
| 最低同步间隔 | 5 分钟 | 两次自动同步的最小间隔 |
| Python 路径 | `python` | 执行生成脚本的解释器 |
| 同步完成后提示 | 开 | 完成后弹 Notice |
| 启动时检查离线改动 | 开 | 补跑 Obsidian 关闭期间的改动 |
| 立即同步 | — | 手动触发，不受最低间隔限制 |

### 触发规则

- 只看 `.md`；忽略 `00_系统` / `00_Inbox` / `00_附件` / `template` / `Clippings` / `归档` / `private`
- 内容 hash 前去掉所有空白：只改空格、缩进、空行不触发
- 新建、删除、改名、正文改动会触发
- Inbox 内的一切变化不触发；整理进主题目录才触发
- 延迟期间关闭 Obsidian，`pendingSync` 会持久化，下次启动补跑

### 生成脚本

- `00_系统/脚本/生成知识库导航页.py` — 导航页
- `00_系统/脚本/生成玻璃展厅.py` — 展厅数据

两个脚本都支持未跟踪（未 commit）的新笔记；有 git 首次入库时间时优先用它，否则用文件创建时间。

## 关闭整套玻璃

设置 → 外观 → CSS 代码片段 → 关闭 `glass-workbench`。不会影响笔记内容。
