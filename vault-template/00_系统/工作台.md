> [!tip] 维护说明
> 1. 快捷入口与「今日焦点」直接改本页文字。
> 2. 玻璃外观来自 `.obsidian/snippets/glass-workbench.css`，在 **设置 → 外观 → CSS 代码片段** 可开关。
> 3. 配色 / **关闭配色** / 模糊 / 双栏 / 省电模式，都在 **设置 → Style Settings → Prism Glass 工作台**。
> 4. 双栏仅在阅读视图生效（`Ctrl+E` 切换）；编辑视图保持单栏，避免打断输入。
> 5. 想让**某一篇笔记单独用别的配色**：在它的 frontmatter 里写 `cssclasses: [glass-dashboard, pg-us11]`，会覆盖全局配色（可用 pg-us00/11/08/05/02/13/15/12）。
> 6. 玻璃展厅是独立 HTML；**Obsidian 的 HTML 阅读器对脚本/WebGL 有限制，可能显示为静态**，完整体验请用浏览器打开。日常交互请用 [[00_系统/交互工作台|⚡ 交互工作台]]。
> 7. **自动同步**：笔记实质内容变化后，`Workbench Sync` 插件会重新生成导航页与展厅，并刷新 Dataview。去抖 8 秒、**最低间隔 5 分钟**；只改空格/空行/光标位置不会触发，Inbox 的变化也不触发（整理进主题目录才算）。整理完想立刻看到 → 设置 → Workbench Sync → **立即同步**。
