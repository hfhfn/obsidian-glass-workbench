# 🎨 玻璃工作台 · 配色方案

> [!abstract] 怎么用
> - **全局切换**：设置 → Style Settings → Prism Glass 工作台 → 配色方案（共 18 套，含 4 套炫彩）
> - **只想恢复主题色**：打开「关闭配色（跟随主题）」，颜色回到 Blue Topaz，玻璃与布局保留
> - **单篇笔记另用配色**：在那篇的 frontmatter 写 `cssclasses: [glass-dashboard, pg-us16]`

## 设计原则

1. **材质稳定，只换氛围**：玻璃分层、圆角、间距不变，只替换 Canvas / Surface / Accent / Highlight 五层语义色。
2. **70–90% 中性**：大面积留给深色画布与玻璃，强调色只占 10–30%，避免整页发光。
3. **先算对比度再选色**：强调色在卡片底上 ≥ 4.5:1，弱化文字 ≥ 4.5:1。
4. **暗玻璃不靠纯黑**：用深蓝 / 石墨 / 深褐代替 #000，长时间看不发闷。
5. **一个配色一个性格**：暖（琥珀 / 赤陶）、冷（电蓝 / 东京夜）、中性（莫兰迪），按场景挑而不是按好看挑。

---

## 推荐组合

- **日常主力**：US-16 墨蓝琥珀（暖冷平衡）或 US-17 石墨电蓝（最稳）
- **夜间长读**：US-18 东京夜
- **写作 / 整理**：US-19 雾青莫兰迪
- **AIGC / 展示**：US-20 紫檀玫金
- **想更炫**：US-22 霓虹青紫 + 打开「炫彩渐变」
- **不想要颜色**：打开「关闭配色（跟随主题）」
